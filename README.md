# Kwast
Интерактивный пилот мобильной биржи малярных работ в Нидерландах. Русский интерфейс, демонстрационные компании, локальные данные на устройстве. Внутри — общий офлайн-интерфейс и отдельные проекты Android и iOS. Код не содержит платёжных ключей и клиентских документов.

## Android
Открыть mobile/android в Android Studio с JDK 17 и SDK 35. При необходимости выбрать локальный Gradle 8.9. Собрать модуль app и запустить на эмуляторе или устройстве Android 8+. Проект включает интерфейс из dist в приложение. Путь к dist следует сохранить. Для выпуска нужна подпись владельца приложения.

## iOS
Открыть mobile/ios/Kwast.xcodeproj в Xcode 16 на Mac. Выбрать схему Kwast и симулятор iOS 16+. Для личного устройства выбрать свою команду в Signing & Capabilities. Папка dist включается в пакет при сборке. Проект не содержит сертификата для распространения.

## Браузер
Папка dist — самостоятельная статическая сборка. Запустить из корня проекта команду python3 -m http.server 8000 --directory dist и перейти на http://localhost:8000. Для установки веб-приложения на телефон использовать HTTPS.

## Границы пилота
Сценарии регистрации, портфолио, откликов, брони и комиссии предназначены для демонстрации. Смена компании на одном устройстве имитирует две стороны. Участники с разных устройств не обмениваются заявками. Используйте вымышленные данные. Для коммерческой эксплуатации потребуются серверные аккаунты и права доступа, обработка документов, синхронизация броней и платёжный партнёр.
